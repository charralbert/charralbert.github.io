Taxi Trip Estimator

Refer to my team's code here Taxi Trip GitHub Repository

In a team of four, we created a Taxi Trip Duration estimator using a KNN regression model. The model takes the input features: pickup and drop-off coordinates, pickup and drop-off datetime, vendor ID, passenger count, and store-and-forward flag (A flag indicating whether the trip data was stored in the taxi’s memory before being sent to the central server).
